GitHub Copilot: # Опис категорій та алгоритму класифікації витрат Direct Cost Master

## Передумови та контекст

Direct Cost Master обробляє файли P&L (Profit & Loss) у форматі Excel, які містять дані про прямі витрати за різні періоди. Кожен файл може містити дані за декілька місяців, але обробка відбувається для одного обраного місяця.

Система працює з двома типами витрат:
- **DL Costs (Direct Labor)** - прямі трудові витрати
- **VC Costs (Variable Costs)** - змінні витрати

## Попередньо визначені категорії (Buckets)

### Для DL Costs (Direct Labor):
1. **"Discrepancies & corrections from previous month"** - корекції з попереднього місяця
2. **"PM role charge"** - витрати на роль проект-менеджера
3. **"Paid overtime"** - оплачені понаднормові години
4. **"Need clarification"** - базові зарплатні витрати (потребують уточнення)
5. **"Sick leave"** - оплата лікарняних
6. **"Medical Insurance"** - медичне страхування
7. **"Bonus"** - бонуси та премії

### Для VC Costs (Variable Costs):
1. **"Discrepancies & corrections from previous month"** - корекції з попереднього місяця
2. **"Recruiting cost"** - витрати на підбір персоналу
3. **"DC - other DC"** - інші прямі витрати

## Алгоритм класифікації DL Costs (пріоритет виконання)

### Етап 1: Передобробка даних
```python
# Отримання значень з відповідних колонок
total_hours_direct_val = get_cost('Total Hours Direct')

sick_leave_val = get_cost('Sick Leave Paid')
medical_insurance_val = get_cost('Medical Insurance')
bonus_val = get_cost('Unconditional Bonus')
```

### Етап 2: Класифікація (в порядку пріоритету)

#### 1. **Перевірка на корекції** (найвищий пріоритет)
```python
if total_hours_direct_val < 0:
    bucket = 'Discrepancies & corrections from previous month'
    # ЗУПИНИТИ подальшу обробку цього рядка
```
**Логіка**: Від'ємні години завжди означають корекції з попереднього періоду.

#### 2. **PM role charge** (спеціальний випадок)
```python
if 'pm role charge' in employee_ticket.lower():
    bucket = 'PM role charge'
    cost = total_dl_costs_val
    # ЗУПИНИТИ подальшу обробку цього рядка
```
**Логіка**: Записи з "PM role charge" в імені завжди відносяться до витрат на проект-менеджмент.

#### 3. **Paid Overtime** (включає базові компоненти)
```python
if paid_overtime_val > 0:
    total_cost = paid_overtime_val + base_salary_val + payroll_taxes_val + 
                 vacation_liability_val + paid_vacation_val
    bucket = 'Paid overtime'
```
**Логіка**: Якщо є понаднормові, вони включають базову зарплату та всі пов'язані витрати.

#### 4. **Need clarification** (базові витрати, якщо немає понаднормових)
```python
else:  # тільки якщо paid_overtime_val == 0
    total_cost = base_salary_val + payroll_taxes_val + 
                 vacation_liability_val + paid_vacation_val
    bucket = 'Need clarification'
```
**Логіка**: Стандартні зарплатні витрати без понаднормових.

#### 5-7. **Незалежні категорії** (можуть співіснувати з попередніми)

##### 5. Sick Leave
```python
if sick_leave_val > 0:
    bucket = 'Sick leave'

    hours = sick_hours_val
```

##### 6. Medical Insurance

## Ключові особливості логіки

### 1. **Пріоритет обробки**
- Корекції (від'ємні значення) мають найвищий пріоритет
- PM role charge - спеціальний випадок
- Paid Overtime включає базові компоненти
- Незалежні категорії (Sick leave, Medical Insurance, Bonus) можуть співіснувати

### 2. **Множинні записи з одного рядка**
Один рядок Excel може генерувати декілька записів у різних категоріях:
```python
# Приклад: працівник може мати одночасно
# - "Need clarification" (базова зарплата)
# - "Sick leave" (лікарняні)
# - "Medical Insurance" (страхування)
```

### 3. **Округлення**
Всі грошові суми округлюються до 2 знаків після коми:
```python
return round(value, 2)
```

### 4. **Обробка помилок**
- Пропускаються порожні рядки
- Ігноруються рядки з "total" у назві
- Логування помилок без зупинки обробки

### 5. **Структура даних результату**
Кожен запис містить:
- **Employee/Item**: ім'я працівника або назва позиції
- **Project**: назва проекту (з імені файлу)
- **Month**: місяць обробки
- **Bucket**: категорія витрат
- **DC Hours**: кількість годин (0 для VC)
- **Total DL costs**: загальна сума витрат

Ця логіка забезпечує точну класифікацію всіх типів витрат згідно з бізнес-правилами організації.
